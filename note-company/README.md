# note出版部 — あなたの仕事を代行するAIチーム

個人事業主の「社長」が、note有料記事の制作とThreadsでの集客を、AI社員のチームに任せるための仕組みです。
Claude Code でこのフォルダを開くと、社員とコマンドが使えるようになります。

## 組織図

```
            社長(あなた) ── 指示・承認・公開
               │
        秘書兼編集長(メインのClaude)
   ┌──────┬──────┼──────┬──────────┐
リサーチ    ライター    編集者     SNS担当        秘書
researcher  writer     editor   threads-marketer  secretary
ネタ・調査  執筆       校正・価格  Threads投稿      Gmail
```

## はじめ方(最初の1回だけ)

1. **このフォルダで Claude Code を起動する**
   ```
   cd note-company
   claude
   ```
2. **プロフィールを埋める**:`brand/profile.md` を自分で書くか、Claudeに「プロフィールのインタビューをして」と頼む
3. **Gmail をつなぐ**:claude.ai の 設定 → コネクタ から Gmail を接続する(秘書の仕事に必要)

## 毎日の使い方

| やりたいこと | 入力するもの |
|---|---|
| 朝、連絡と今日やることを確認したい | `/morning-report` |
| 記事のネタを決めたい | `/plan-article`(テーマがあれば `/plan-article 副業の確定申告`) |
| 記事を書いてほしい | `/write-article articles/2026-10-23-xxx/plan.md` |
| Threadsで宣伝したい | `/threads-posts` |
| 週の振り返りをしたい | `/weekly-review` |

普通の言葉で頼んでも大丈夫です(例:「来週の記事を1本書いて」)。

## 1本の記事ができるまで

1. `/plan-article` … リサーチ担当が競合を調べ、企画書を作る → **社長が了承**
2. `/write-article` … 社長に体験を少し聞く → ライターが執筆 → 編集者が校正、タイトル・価格を提案
3. **社長が `final.md` を確認**し、空欄を埋めて、noteに貼り付けて公開(有料ラインに境界線を置く)
4. `/threads-posts` … 1週間分の宣伝投稿ができる → **社長がThreadsに投稿**

## 安全のための決まり

- メールの送信、Threadsへの投稿、noteへの公開は、**必ず社長が自分で行います**。AI社員が作るのは下書きまでです
- 体験談や実績をでっち上げません。社長にしか書けない箇所は空欄で残します
- 詳しい社内ルールは `CLAUDE.md` にあります

## 自動化したくなったら

- **毎朝の自動報告**:Claudeに「平日の朝8時に /morning-report を実行するスケジュールを組んで」と頼む
- **Threadsへの予約投稿**:Threads(Meta)の予約投稿機能を使うか、Threads APIの連携を追加で作る

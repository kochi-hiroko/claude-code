# 執筆ルール(note有料記事)

## 記事の基本構成

1. **タイトル**:読者が得るもの + 具体性(数字・期間・対象)。32文字前後まで。
2. **無料部分**(全体の2〜3割)
   - 読者の悩みに共感する
   - この記事で何が分かるか(目次や箇条書きで約束する)
   - 誰向けか / 誰向けでないか
   - 書き手が語れる理由(実績・体験)
   - 無料部分だけでも1つは役に立つ話を入れる
3. **有料ライン**:`---- ここから有料 ----` と書いておく(noteの有料エリア境界線をここに置く)
4. **有料部分**(全体の7〜8割)
   - 具体的な手順、テンプレート、実例、数字
   - 読者がそのまま真似できる形にする
5. **まとめ**:要点の振り返りと、次にやる行動を1つ

## 書き方

- 1文は60文字以内を目安にする。長い文は分ける
- 見出し(大見出し・小見出し)を使い、流し読みでも分かるようにする
- 抽象的な話のあとには、必ず具体例を1つ入れる
- 「〜と言われています」のような根拠のない書き方は使わない
- 煽り(「知らないと損」「絶対」「誰でも簡単に」)は控えめにする
- 文字数の目安:有料記事は5,000〜10,000字

## Threads投稿ルール

- 1投稿500文字以内(Threadsの上限)。基本は150〜300文字
- 1行目で手を止めさせる(問いかけ、意外な事実、数字)
- 投稿の6〜7割は役に立つ話だけにする。宣伝は3〜4割まで
- noteのリンクは宣伝の投稿にだけ付ける。リンクを付ける投稿でも、それ単体で役に立つ中身にする
- ハッシュタグ(トピック)は1つまで

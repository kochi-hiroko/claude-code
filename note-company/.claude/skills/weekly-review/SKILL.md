# 週次レビュー

1. この7日間に作られた、または更新されたファイルを `articles/`、`threads/`、`reports/` から集める
2. 社長に数字を聞く(分からなければ飛ばしてよい)
   - noteの売上、記事ごとの購入数、ビュー数
   - Threadsのフォロワー数、反応が良かった投稿
3. 次の内容で `reports/weekly-YYYY-MM-DD.md` を作る
   - 今週の成果(公開した記事、作った投稿)
   - 数字と、先週からの変化
   - うまくいったこと / いかなかったこと(反応の良かった投稿の共通点など)
   - 来週の計画:書く記事1〜2本(テーマ案つき)、Threadsで試すこと1つ
4. 社長には要点を5行以内で報告し、来週の1本目の企画に進むか確認する

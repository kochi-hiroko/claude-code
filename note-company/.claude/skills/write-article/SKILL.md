# 記事制作ライン

対象:$ARGUMENTS

1. **企画**:企画書(`plan.md`)が指定されていなければ、先に `plan-article` スキルの手順で作り、社長の了承をもらう
2. **社長への取材**:企画書の「社長に聞きたいこと」を社長に質問する。社長が「あとで」と言ったら空欄のまま進める
3. **執筆**:`writer` に企画書のパスと取材の答えを渡し、`draft.md` を書かせる
4. **事実確認**:下書きに `【要確認】` があれば、`researcher` に確認させ、結果を下書きに反映する
5. **校正**:`editor` に `final.md` と `review.md` を作らせる
6. **報告**:社長に次を伝える
   - おすすめタイトルと価格
   - 文字数(無料部分 / 有料部分)
   - 公開前に社長がやること(空欄の記入など)
   - `final.md` の場所
7. 「Threadsの宣伝投稿も作りますか?」と聞く(作るなら `threads-posts` スキルへ)

noteへの公開は社長が自分で行う。公開するときは、`---- ここから有料 ----` の位置にnoteの有料エリア境界線を置き、その行は消す。

# 記事の企画書づくり

テーマ:$ARGUMENTS

1. `brand/profile.md` を読む。空欄が多い場合は、先に社長へ3〜5問だけ質問してから進める
2. テーマが指定されていなければ、`researcher` にネタを5つ探させ、社長に選んでもらう
3. `researcher` に、そのテーマの競合調査をさせる(人気記事の傾向、価格、足りていない切り口)
4. 次の内容で企画書を作り、`articles/YYYY-MM-DD-スラッグ/plan.md` に保存する(日付は今日、スラッグは英数字の短い名前)

```
# 企画書:(仮タイトル)
- 読者:誰の、どんな悩みか
- 読後の変化:読み終えた読者が、何をできるようになるか
- 差別化:競合と比べて、何が違うか
- 想定価格:
- 無料部分で伝えること:
- 有料部分で渡すもの:(手順、テンプレート、実例など具体的に)
- 構成案:(大見出し・小見出し)
- 社長に聞きたいこと・入れてほしい体験:
- 参考にした情報(出典URL):
```

5. 社長に企画の要点を5行以内で報告し、「この内容で執筆に進めますか?」と確認する

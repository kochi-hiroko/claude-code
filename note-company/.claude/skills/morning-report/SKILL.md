# 朝の報告

1. `secretary` に、Gmail の確認をさせる(前回の `reports/morning-*.md` があれば、その時刻以降を対象にする)
   - コネクタがつながっていない場合は、その旨と、claude.ai の設定 → コネクタ からつなげることを社長に伝え、制作タスクだけ報告する
2. `articles/` を見て、制作中の記事の状態をまとめる
   - `plan.md` だけ → 企画の了承待ち
   - `draft.md` まで → 校正待ち
   - `final.md` あり → 社長の確認・公開待ち(空欄が残っていれば件数)
3. `threads/` を見て、今日の投稿予定があれば本文を載せる
4. 次の形で `reports/morning-YYYY-MM-DD.md` に保存し、同じ内容を社長に報告する

```
# 朝の報告 YYYY-MM-DD
## 今日やること(3つまで)
## 🔴 今日中に対応する連絡
## 🟡 今週中に対応する連絡
## 制作の進み具合
## 今日のThreads投稿
```
